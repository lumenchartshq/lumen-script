# Contributing

Thanks for your interest in Lumen Script.

## Pull requests

We are not accepting pull requests at the moment, so opening them is limited to
maintainers. This repository is published from the Lumen Charts development
repository, and each release arrives here as a single commit. Outside
contributions will need a signed contributor agreement before we can accept
them, because Lumen Script is also offered under a commercial licence.

## Issues

Bug reports are welcome as
[issues](https://github.com/lumenchartshq/lumen-script/issues). Include the
package version, the smallest script that shows the problem, and the bars it
ran on.

## Building locally

```bash
pnpm install
pnpm build
pnpm typecheck
pnpm test
```

## Reporting security issues

Please do not open a public issue. Email support@lumencharts.com instead.
